# Horizon Essentials

Extension complémentaire pour [Horizon](https://playhorizon.dev) (Minecraft: Java Edition 26.3 réécrit en Rust) :
un mod natif (`.hnmod`) qui ajoute ce que Horizon n'a pas encore, sans refaire ce qu'il a déjà.

| Fonction | Ce qu'elle ajoute à Horizon |
|---|---|
| HUD Profiles | Profils PvP, Survival, Minimaliste, Personnalisé pour nos widgets |
| Advanced Keystrokes | Shift, couleurs et tailles par touche |
| CPS History | Historique des clics, pic, moyenne |
| FPS Statistics | Min, max, 1 % low, mini-graphe |
| Memory Display | Mémoire privée/résidente du jeu, % de la RAM |
| HUD Customizer | Position, taille, couleurs, fond de chaque widget, éditeur glisser-déposer |
| Essentials Core | Paramètres en cache, profils, sauvegarde différée |

État : **étape 0** (environnement et chaîne de compilation). Aucun code du mod pour l'instant.
